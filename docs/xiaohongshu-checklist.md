# 小红书上传与操作进度清单

更新时间：2026-11-03

范围：向 `content_discovery_event` 表写入作品（图文/视频）、`COMMENT`、`USER` 三类事件，建立 作品 → 评论 → 用户的关联，并覆盖批量操作。

链路策略标注：
- `[双链路]`：`MediaCrawler`（服务端协议批量读）与 `手机端`（真机 UI 自动化）均需实现，共用同一套事件入库结构。
- `[仅 MediaCrawler]`：仅在服务端协议爬虫实现（高并发翻页、直接提取接口结构化字段、账号与代理池轮换）。
- `[仅手机端]`：仅在真机 App 端实现（双列流控件点击与返回保护、剪贴板短链读取、以及全部高权重触达写操作）。

勾选表示该项已实现并完成所注明的验证。代码接入但尚未验证的项目保持未勾选；收到 ACK 不等于已经完成数据库字段验收。

## 第一批 作品 NOTE / VIDEO（含图文与视频）

- [ ] `[双链路]` 自动识别并上报作品类型 `payload.noteType`（图文 `IMAGE_TEXT` / 视频 `VIDEO`）。
- [ ] `[双链路]` 采集图文标题 `payload.title`、正文 `payload.description`（手机端视频页展开左下角文案采集；`MediaCrawler` 直接取接口 `title`/`desc`）。
- [ ] `[双链路]` 采集作者昵称 `payload.authorNickname`。
- [ ] `[双链路]` 采集作者小红书号 `payload.authorDouyinId`（手机端进作者主页识别 `小红书号：xxxx`；`MediaCrawler` 从主页 HTML/接口提取 `red_id`）。
- [ ] `[双链路]` 携带事件 ID、授权码、设备/节点标识、来源模式、作品类型和采集时间，收到服务端 ACK。
- [ ] `[双链路]` 确认 24 位作品 ID `payload.awemeId`（`noteId`）入库补全（`MediaCrawler` 直接写入 `note_id`；手机端上报 `xhslink.com` 短链由服务端解析补全）。
- [ ] `[仅手机端]` 双列瀑布流通过可见卡片控件及实际边界点击进入详情页，记录已点卡片避免重复进入。
- [ ] `[仅手机端]` 采集作品分享短链 `payload.videoUrl`（图文页从右上角分享采集，视频页从右侧分享采集，支持焦点窗读取剪贴板）。
- [ ] `[仅手机端]` 单次采集后核对作者和标题/文案，返回原作品详情页；作品处理完成后退回双列瀑布流原位置。
- [ ] `[仅 MediaCrawler]` 采集带 `xsec_token` 的作品长链 `payload.videoUrl`，支持详情接口失败时降级解析网页 `__INITIAL_STATE__`。
- [ ] `[双链路]` 用作品查询 SQL 核对链接、作品 ID、作品类型、作者昵称、作者小红书号和时间。
- [ ] `[双链路]` 第一批整体验收通过。

## 第二批 评论 COMMENT

- [ ] `[双链路]` 采集评论者昵称 `payload.nickname`。
- [ ] `[双链路]` 采集评论正文 `payload.content`。
- [ ] `[双链路]` 采集评论时间 `payload.commentTime` 及 IP 属地 `payload.ipLocation`。
- [ ] `[双链路]` 采集二级子评论（手机端点击「展开回复」；`MediaCrawler` 调用 `/v2/comment/sub/page` 游标翻页）。
- [ ] `[双链路]` 填充评论者小红书号 `payload.authorDouyinId`，与第三批主页采集回填衔接。
- [ ] `[双链路]` 设置 `parent_event_id`，关联所属作品的 `event_id`。
- [ ] `[双链路]` 接入评论事件本地保存、重传和 ACK 清理。
- [ ] `[双链路]` 验证重复评论去重，以及不同作品下相同评论不会误合并。
- [ ] `[仅手机端]` 图文页下滑正文进入内联评论区；视频页点击评论图标打开半屏评论抽屉。
- [ ] `[仅 MediaCrawler]` 调用 `/v2/comment/page` 接口按 `cursor` 游标批量并发拉取全量一级评论。
- [ ] `[双链路]` 用评论查询 SQL 和作品评论关联 SQL 验收。
- [ ] `[双链路]` 第二批整体验收通过。

## 第三批 评论用户 USER

- [ ] `[双链路]` 采集评论者主页小红书号 `payload.douyinId`（`小红书号：xxxx`）及粉丝数、作品数。
- [ ] `[双链路]` 设置 `parent_event_id`，关联所属评论的 `event_id`。
- [ ] `[双链路]` 接入用户事件本地保存、重传和 ACK 清理。
- [ ] `[双链路]` 验证服务端将用户小红书号回填到评论的 `payload.authorDouyinId`。
- [ ] `[仅手机端]` 从对应评论点击进入评论者主页，确认昵称身份对应正确，记录实际触达状态 `payload.touchStatus`。
- [ ] `[仅手机端]` 验证返回评论区（图文内联评论区 / 视频评论抽屉）后继续任务，不串联其他用户或作品。
- [ ] `[仅 MediaCrawler]` 根据评论区的 `user_id` 与 `xsec_token` 批量请求用户主页提取创作者资料（默认 `touchStatus = UNTOUCHED`）。
- [ ] `[双链路]` 用 COMMENT 与 USER 关联查询 SQL 验收。
- [ ] `[双链路]` 第三批整体验收通过。

## 批量操作（互动与发布）

- [ ] `[仅手机端]` 作品级互动：按配置执行图文/视频点赞、收藏、发表一级评论，并校验状态生效。
- [ ] `[仅手机端]` 评论区触达：对目标评论执行点赞（`payload.commentLiked`）与回复（`payload.commentReplied`）。
- [ ] `[仅手机端]` 插队评论回复：支持接收远程指令（如 `MediaCrawler` 筛出的高意向评论）定位指定作品与目标评论并完成回复。
- [ ] `[仅手机端]` 主页触达：按条件执行关注、主页首篇作品点赞/收藏、发送私信，上报 `payload.profileActionsPerformed`。
- [ ] `[仅手机端]` 作品发布：支持发布图文笔记与视频笔记。
- [ ] `[仅手机端]` 通知回复：巡检消息中心未读评论与 `@`，支持就地回复与点赞。
- [ ] `[仅手机端]` 接入每日互动配额限制（点赞、收藏、评论、关注、私信独立计数）。

## 模式接入

- [ ] `[双链路]` 发现页推荐模式（`RECOMMEND`）：手机端双列流选帖互动；`MediaCrawler` 调用 `homefeed` 接口批量采集。
- [ ] `[双链路]` 普通搜索模式（`SEARCH`）：支持关键词搜索及筛选（综合/最新/最多评论/最多点赞，笔记类型：不限/视频/图文，发布时间）。
- [ ] `[仅手机端]` 同城/附近模式（`CITY`）。
- [ ] `[仅手机端]` 自动模式中的推荐、搜索、同城阶段及对应 `source_mode`（`AUTO_RECOMMEND` / `AUTO_SEARCH` / `AUTO_CITY`）。

## 上报与可靠性

- [ ] `[双链路]` 作品、评论、用户事件持久化队列，按授权码隔离待发送记录。
- [ ] `[双链路]` 实时包及心跳携带 `discoveryEvents`，每包最多 200 条；仅在收到 `discoveryAckIds` 后删除已确认事件。
- [ ] `[双链路]` 相同链接/作品 ID 重传保持相同事件 ID；停止或断网恢复后完整补报。
- [ ] `[双链路]` 同一作品不同 `xhslink.com` 短链或带 `xsec_token` 长链统一收敛按 24 位 `noteId` 合并去重。
- [ ] `[仅手机端]` 滑块/验证码检测自动暂停保护与多级返回归位防死循环。
- [ ] `[仅 MediaCrawler]` 账号池与代理 IP 池自动轮换、签名服务（`xhshow`）异常重试与断点续爬（`Checkpoint`）。

## 联调与发布验收

- [ ] `[双链路]` 本地通过事件队列、作品类型识别、24 位 `noteId` 提取与去重相关测试。
- [ ] `[双链路]` 数据库 SQL 验收：验证 `MediaCrawler` 与 `手机端` 上报的 作品（图文/视频）→ 评论 → 用户 完整链路，字段格式一致、不串关联。
- [ ] `[双链路]` 验证「`MediaCrawler` 批量采集入库 → 下发目标评论 → `手机端` 插队回复/主页触达」跨链路协同闭环。
- [ ] `[仅手机端]` 多机型分辨率真机验证与正式 APK 重新打包验收。
- [ ] `[仅 MediaCrawler]` 服务器长稳并发采集与签名服务容器化部署验收。
