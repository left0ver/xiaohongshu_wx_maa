## 搜索与运行模式

- [ ] 推荐模式（`RECOMMEND`）：在视频号「推荐」流连续采集与互动，上滑切换并跳过已处理视频。
- [ ] 识别并跳过视频流中的「直播中 / 点击进入直播间」卡片、广告推广卡片及非视频内页，若误入直播间或外链能够自动退出并归位推荐流。
- [ ] 搜索模式（`SEARCH`）：从视频号搜索入口输入关键词搜索，支持切换筛选条件（综合/最新/最热、发布时间等），从搜索结果进入视频连续处理并核对返回结果列表原位置。
- [ ] 朋友 / 关注 / 同城流模式：支持切换顶部「朋友」「关注」或同城入口连续处理视频，自动处理定位权限未开启弹窗（点击 `暂时不了` / `取消`）。
- [ ] 自动模式（`AUTO`）：按配置在推荐、搜索等阶段间自动切换，每次切换后强校验当前页面与目标阶段一致。

## 配额、异常与运行恢复

- [ ] 分别限制每日点赞、推荐/收藏、评论、关注、私信次数（`DailyQuotaStore`），达到上限后阻断对应写操作，重启应用不重置当日已用配额。
- [ ] 检测微信安全验证、滑块或验证码页面后立即零点击暂停，等待人工完成验证后核对干净页面再继续执行。
- [ ] 对加载失败、微信/视频号弹窗（青少年模式、位置权限、新版本提示、意外弹出的分享/更多菜单）或意外页面执行有限次数的返回归位（`bounded_recover_to_target`），超限无法恢复时安全停止并记录原因。
- [ ] 用户停止任务后立即停止后续点击与输入；恢复运行时自动收起残留半屏评论抽屉、输入键盘或弹窗并重新识别当前页面。
- [ ] 对已执行或结果不明确的互动先结合 UI 状态与本地账本核对，避免恢复或重试时重复发表评论、回复或私信。
- [ ] 验证连续多视频、多位评论者的长稳运行，适配不同机型分辨率与微信浅色/深色界面，完整记录阶段耗时、恢复事件与失败原因。

## 建议实施顺序

1. **第一批性能优化与连续采集**：先解决微信控件树空树反复探测与 Agent RPC 模板/OCR 慢的问题，将单视频耗时压降下来，并补齐推荐流上滑连续采集多条视频与跳过直播/广告卡片。
2. **第二批评论抽屉完整采集**：补齐折叠长评展开、评论列表翻页去重、到底/空态判定、二级回复展开与回复对象提取，清理评论昵称徽章混入。
3. **第三批评论者身份与主页往返**：实现点击评论者头像查看资料卡/主页、提取视频号 ID（兼容无视频号普通微信用户）、多位评论者往返与原评论锚点恢复。
4. **互动触达、消息巡检、多运行模式与配额恢复**：依次接入作品/评论互动、主页触达、个人页消息处理、关键词搜索模式，以及每日配额、验证码暂停与有界异常恢复。
